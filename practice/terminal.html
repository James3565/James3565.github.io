ACTUAL USEFUL TERMINAL COMMANDS

  • pwd shows your current folder.
  • ls lists files and folder.
  • cd changes folders.
  • mkdir creats a new folder.

HOW TO CREATE A FOLDER

  1. Open Terminal.
  2. Type mkdir practice.
  3. press Enter.
  4. Type cd practice.

                    cd practice
                    touch index.html
